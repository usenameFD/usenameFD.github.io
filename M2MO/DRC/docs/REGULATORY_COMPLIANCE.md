# CRR3 / FRTB-SA Compliance Checklist

## CRR3 Article 325bd Requirements

- [x] Calculation at least weekly
- [x] VaR at 99.9% confidence
- [x] On 1-year horizon
- [x] Minimum 2 systematic factors
- [x] Pre-announced computation dates
- [x] Documented methodology
- [x] Audit trail maintained
- [x] Stress testing protocol

## Equity-Specific (Article 325y)

- [x] LGD for equities: 60-100% (using 100%)
- [x] JTD = current market value
- [x] Separate from counterparty risk
- [x] Liquidity horizon: 10 days

## FRTB-SA Standards

- [x] Correlation matrix from market data
- [x] Stressed period calibration
- [x] At least 2 factors (using 5-7)
- [x] Importance sampling for tail
- [x] Backtesting performed
- [x] Model validation documented

## Governance Checklist

- [x] Risk committee oversight
- [x] Independent valuation
- [x] Limiting procedures
- [x] Exception reporting
- [x] System redundancy
- [x] Disaster recovery
