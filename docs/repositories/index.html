Code et dépôts publics

Sélection de dépôts GitHub liés aux projets du portfolio

Cette page présente une sélection de mes dépôts publics, retenus pour leur pertinence quantitative et leur niveau de documentation. Elle ne reproduit pas l’intégralité de mon compte GitHub.

NoteCritères de sélection

Un dépôt figure ici s’il remplit les trois conditions suivantes : il relève de la finance quantitative, de la modélisation statistique ou de la donnée appliquée ; il est suffisamment documenté pour être lu sans contexte supplémentaire ; et il correspond à un travail dont je suis l’auteur ou le co-auteur. Sont exclus les forks sans contribution substantielle, les exercices de cours isolés et les dépôts sans documentation.

Les métadonnées affichées (nom, description, langage, licence) ont été vérifiées manuellement. Aucun appel à l’API GitHub n’est effectué lors de la consultation ou de la génération de ce site.
